HOW TO USE: brain-update
=========================

PURPOSE
  Directly replace the content of an obsolete or reversed Second Brain memory
  with updated facts, decisions, or code patterns.

CAPABILITIES
  - Replaces outdated memory content completely
  - Supports updating tags and volatility flags (!durable, !state, !volatile)
  - Direct command execution carries automatic permission

USE CASES
  - Overwriting an architecture choice that was officially replaced
  - Correcting an outdated setup instruction or configuration file path
  - Updating a documented workflow to match a new tool release

IDEAS
  - If you only want to add a note while keeping the old text, prefer `/brain-append`
  - Use `/brain-update` when the previous info is completely obsolete or incorrect

PROMPTS YOU CAN PASTE
  /brain-update mem_8f93a1 Now using event-driven model instead of polling #architecture !durable

  /brain-update mem_abc123 Switched to Simpler in Ableton instead of Drum Rack

EXAMPLE FLOW
  You: /brain-update mem_8f93a1 Now using event-driven model instead of polling #architecture !durable
  Agent: [Calls update MCP tool immediately, reports updated memory ID and new content]

DEFAULT GOALS IF YOU DON'T NAME ONE
  1. Parse target ID and new content
  2. Execute update MCP tool immediately
  3. Report confirmed replacement to target memory
